# blazor-dbz-api-personagem

Atividade de Desenvolvimento Web feita em Blazor (.NET).

Autor: Kaio Eduardo de Oliveira Barbosa

Sobre o projeto

Aplicação simples que consome a API do anime Dragon Ball. O usuário digita o ID de um personagem e a página mostra:

Nome
Planeta de origem
Transformações

API utilizada: https://dragonball-api.com/api/characters/{id}

Como executar
bash
dotnet run

Depois é só abrir o endereço que aparecer no terminal.
